Function reference

This page is generated from the package’s own man/*.Rd files by data-raw/build_reference.R, so it cannot drift from the roxygen. Full documentation for any function is ?name in an R session.

opus exports 34 functions. The yaml dictionaries are the deliverable; these are the tooling around them.

The specification

The dictionary as data. Downstream code should reach the yaml through these rather than parsing it, so there is one place where the shape of the specification is known.

Converting DATRAS XML to parquet

The four steps of the conversion, in the order they must run: physical types, then names, then sentinels, then the semantic types the wire cannot express. A consumer calling these on its own live fetch gets a result identical to the published archive rather than a near-miss.

Function
op_cast_wsdl_types() Cast a parsed DATRAS table to its WSDL-declared physical types
op_rename_to_new() Rename a DATRAS table from ICES’s legacy names to opus’s current names
op_strip_sentinels() Replace sentinels with NA, where they mean absence
op_cast_to_spec() Realise the semantic types the wire format cannot express
op_wsdl_type_overrides() The documented WSDL type overrides

Sentinels

DATRAS overloads -9: in most fields it means “not recorded”, in a few it is a documented answer. These read the registry, resolve it to a per-column verdict, and measure the result against real data.

Function
op_sentinels() Read the sentinel registry
op_sentinel_policy() Resolve, per column, whether a sentinel means absence
op_sentinel_audit() Count sentinel values per column in a parquet file

ICES is renaming DATRAS fields one table at a time. These separate what ICES claims about renames from what survives checking against what the service actually returns.
